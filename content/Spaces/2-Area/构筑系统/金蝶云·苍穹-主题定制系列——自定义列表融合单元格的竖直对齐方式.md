## 用户场景

列表融合单元格的竖直方向对齐，为了整体协调和性能考虑，默认为居上对齐，考虑到部分用户会用居中的需求和兼容考虑，在主题定制中暴露可以配置的参数，用户可以用来修改列表融合单元格的竖直对齐方式。

## 功能介绍

使用前，推荐先阅读[《主题定制》](https://vip.kingdee.com/article/90752877873775360)  
用户可以自定义配置融合单元格的竖[《主题定制》](https://vip.kingdee.com/article/90752877873775360)直对齐方式，目前有两种模式：(注意复制到系统时需删除注释)

1. `top`：居上，不固定位置，在融合单元格较多时滚动显示内容会消失，默认。
2. `middle` : 固定居中显示，内容会随着滚动一直居中。

```json
{
    "defaultProps": {
		"reportGrid": {
				"rowMergeCellVerticalAlign": "middle"   
		}
    }
}
```

## 操作步骤

1. 通过应用-配置工具-主题定制 进入主题的定制界
2. 可以新增主题或者在已有的主题基础上修改，演示上是新增了一个主题  
3. 最后保存，在个人配置界面切换刚刚配置好的主题，可以发现融合的单元格竖直对齐方式就修改成居中了~
