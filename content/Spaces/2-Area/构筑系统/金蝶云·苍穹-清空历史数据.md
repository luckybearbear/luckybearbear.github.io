## 查询需要删除的表

```sql
select * from pg_tables where schemaname='public'
and (tablename like 'pxtc%' or tablename like 'tk_pxtc%')
and tablename  not like 'pxtc_object_api%'
and tablename  not like 'pxtc_connection_type%'
and tablename  not like 'pxtc_execute_count%'
--客户 OK
and tablename not like 'pxtc_customer%'
and tablename not like 'pxtc_customer_contact%'
--供应商 OK
and tablename not like 'pxtc_supplier%'
and tablename not like 'pxtc_supplier_contact%'
--排程参数 OK
and tablename not like 'pxtc_aps_config%'
--班别设定 OK
and tablename not like 'pxtc_aps_class%'
--加工资源配置 OK
and tablename not like 'pxtc_user_deploy%'
--设备管理 OK
and tablename not like 'pxtc_device%'
and tablename <> 'pxtc_op_types'
--材质定义 OK
and tablename not like 'pxtc_material_type%'
--模具分类 OK
and tablename not like 'pxtc_wo_type%'
--工序类型 OK
and tablename not like 'pxtc_operation_type%'
--工段定义 OK
and tablename not like 'pxtc_section_type%'
--资产类型 OK
and tablename not like 'pxtc_assets_type%'
--备料类型 OK
and tablename not like 'pxtc_stock_type%'
--物料类型 OK
and tablename not like 'pxtc_industry_type%'
--物料料号 OK
and tablename not like 'pxtc_material%'
--问题点类型 OK
and tablename not like 'pxtc_question_type%'
--产品类型 OK
and tablename not like 'tk_pxtc_goods%'
--加工费率 OK
and tablename not like 'pxtc_process_rate_base%'
--物料归类 OK
and tablename not like 'pxtc_material_class%'
--制品类型 OK
and tablename not like 'pxtc_item_type%'
--点检项目 OK
and tablename not like 'pxtc_bench_check%'
--看板 OK
and tablename not like 'pxtc_screen%'
;
```

## 生成清空表的语句

将`tablename`这一列复制到EXCEL中A列，在B1中添加以下函数

```text
=CONCAT("truncate tablename ",A1,";")
```
