> [!INFO] 提示
> 在金蝶云·苍穹平台中，通过客户端回调机制实现页面加载后自动聚焦到输入框，并通过前端事件监听实现回车触发按钮点击，适用于扫码枪等需要快速输入的场景。

## 正文

### 场景说明

在某些业务场景下（如扫码入库），需要：

1. 页面加载完成后自动将焦点设置到指定的输入框
2. 扫码枪输入后（回车键）自动触发业务处理

### 实现原理

**后端部分**：Java 插件实现自动聚焦
1. 在 `afterBindData` 事件中添加客户端回调
2. 在 `clientCallBack` 事件中处理回调，设置输入框焦点

**前端部分**：JavaScript 监听回车事件
1. 在表单初始化事件中绑定 `keydown` 监听
2. 检测回车键（keyCode == 13）后触发按钮点击

### 代码示例

```java
/**
 * 数据绑定完成后事件
 * <p>
 * 设置默认值并添加客户端回调
 * @param e 事件对象
 */
@Override
public void afterBindData(EventObject e) {
    // 添加客户端回调以设置焦点
    this.getView().addClientCallBack(CALLBACK_INIT, 1000);
    super.afterBindData(e);
}

/**
 * 客户端回调事件
 * <p>
 * 在回调中将光标聚焦到扫码输入框
 *
 * @param e 客户端回调事件
 */
@Override
public void clientCallBack(ClientCallBackEvent e) {
    super.clientCallBack(e);
    if (CALLBACK_INIT.equals(e.getName())) {
        TextEdit textEdit = this.getControl(KEY_SCAN_CODE);
        textEdit.setFocus(true);
    }
}
```

### 关键点说明

| 方法/参数 | 说明 |
| --------- | ---- |
| `addClientCallBack(name, delay)` | 注册客户端回调，`delay` 为延迟时间（毫秒） |
| `ClientCallBackEvent.getName()` | 获取回调名称，用于区分不同的回调 |
| `TextEdit.setFocus(true)` | 设置文本框获得焦点 |

### 注意事项

- `addClientCallBack` 的延迟时间需要根据实际情况调整，确保页面渲染完成
- 回调名称建议使用常量定义，便于维护

## 前端配置

在表单的「表单初始化」事件中添加前端代码，监听输入框的回车事件并触发按钮点击。

### 代码示例

```javascript
this.$('pxtc_textfield').on('keydown', (event) => {
  event = event || window.event;
  if (event.keyCode == 13) {
    // 监听回车事件
    setTimeout(() => {
	   // this.$('pxtc_textfield').setValue(this.$('pxtc_textfield').getValue() + '[ENTER]')
      const domEle = this.$('pxtc_enterbtn').getElement();
      domEle.click();
    }, 500)
  }
})
```

### 关键点说明

| 方法/参数 | 说明 |
| --------- | ---- |
| `this.$('control_id')` | 获取指定标识的控件 |
| `.on('keydown', callback)` | 绑定键盘按下事件 |
| `event.keyCode == 13` | 判断是否为回车键 |
| `.getElement()` | 获取控件的 DOM 元素 |
| `.click()` | 触发点击事件 |

### 配置步骤

1. 打开表单设计器
2. 选中表单根节点，在属性面板中找到「表单初始化」事件
3. 点击编辑，粘贴上述代码
4. 修改 `pxtc_textfield` 为实际的输入框标识
5. 修改 `pxtc_enterbtn` 为需要触发的按钮标识

### 注意事项

- 使用 `setTimeout` 延迟执行，确保输入值已完全录入
- 延迟时间可根据实际业务需求调整
- 控件标识需替换为实际业务中的控件标识
