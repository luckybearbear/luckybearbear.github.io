## 概述

本文档介绍如何在苍穹平台报表中实现单元格合并功能，使相同内容的单元格自动合并。

## 应用场景

- 员工报表：相同员工的"计划"和"实际"两行，合并员工姓名列
- 分类汇总：相同分类的数据合并显示
- 主从关系：主表字段合并，明细表字段不合并

## 实现步骤

### 第一步：设置可合并列

在报表界面插件中重写`setMergeColums`方法：

```java
private static final List<String> MERGE_FIELDS = Arrays.asList("userName");

@Override
public void setMergeColums(List<String> columns) {
    // 设置需要合并的列
    columns.addAll(MERGE_FIELDS);
    super.setMergeColums(columns);
}
```

### 第二步：控制合并逻辑

在`packageData`方法中判断何时合并、何时不合并：

```java
@Override
public void packageData(PackageDataEvent packageDataEvent) {
    ReportColumn column = (ReportColumn) packageDataEvent.getSource();
    String fieldKey = column.getFieldKey();

    // 只处理需要合并的列
    if ("userName".equals(fieldKey)) {
        // 当前行员工姓名
        String currentUserName = packageDataEvent.getFormatValue() != null
                ? packageDataEvent.getFormatValue().toString()
                : "";

        // 获取上一行员工姓名（从页面缓存读取）
        String preUserName = this.getPageCache().get("preUserName");

        if (preUserName == null || preUserName.isEmpty()) {
            // 第一行，不需要处理
        } else if (!preUserName.equals(currentUserName)) {
            // 员工姓名不同时，取消合并（开始新的员工组）
            packageDataEvent.getNoMergeKey().addAll(MERGE_FIELDS);
        }
        // 如果员工姓名相同，则保持合并状态（不添加到NoMergeKey）

        // 把当前员工姓名保存到页面缓存中
        this.getPageCache().put("preUserName", currentUserName);
    }

    super.packageData(packageDataEvent);
}
```

**核心逻辑**：
- 相同内容：不添加到`NoMergeKey`，平台会自动合并
- 不同内容：添加到`NoMergeKey`，平台会取消合并

### 第三步：导出时设置合并规则

支持Excel导出时的单元格合并：

```java
@Override
public void exportInitialize(ReportExportInitializeEvent event) {
    List<MergeColumnRule> rules = new ArrayList<>();

    // 设置分组字段 - 按员工姓名分组
    List<String> groupColumns = new ArrayList<>();
    groupColumns.add("userName");

    // 设置合并字段
    List<String> mergeColumns = new ArrayList<>(MERGE_FIELDS);

    // 创建合并规则
    rules.add(new MergeColumnRule(groupColumns, mergeColumns));
    event.setMergeColumnRules(rules);
}
```

## 多列合并

如果需要合并多个列：

```java
private static final List<String> MERGE_FIELDS = Arrays.asList("userName", "deptName");

@Override
public void setMergeColums(List<String> columns) {
    columns.addAll(MERGE_FIELDS);
    super.setMergeColums(columns);
}

@Override
public void packageData(PackageDataEvent packageDataEvent) {
    ReportColumn column = (ReportColumn) packageDataEvent.getSource();
    String fieldKey = column.getFieldKey();

    if ("userName".equals(fieldKey)) {
        String currentUserName = packageDataEvent.getFormatValue() != null
                ? packageDataEvent.getFormatValue().toString()
                : "";
        String preUserName = this.getPageCache().get("preUserName");

        if (preUserName != null && !preUserName.isEmpty() && !preUserName.equals(currentUserName)) {
            packageDataEvent.getNoMergeKey().addAll(MERGE_FIELDS);
        }

        this.getPageCache().put("preUserName", currentUserName);
    }

    super.packageData(packageDataEvent);
}
```

## 条件合并

只合并特定条件的数据：

```java
@Override
public void packageData(PackageDataEvent packageDataEvent) {
    ReportColumn column = (ReportColumn) packageDataEvent.getSource();
    String fieldKey = column.getFieldKey();

    if ("userName".equals(fieldKey)) {
        String currentUserName = packageDataEvent.getFormatValue() != null
                ? packageDataEvent.getFormatValue().toString()
                : "";

        // 跳过合计行，不合并
        if ("合计".equals(currentUserName)) {
            packageDataEvent.getNoMergeKey().addAll(MERGE_FIELDS);
            super.packageData(packageDataEvent);
            return;
        }

        String preUserName = this.getPageCache().get("preUserName");

        if (preUserName != null && !preUserName.isEmpty() && !preUserName.equals(currentUserName)) {
            packageDataEvent.getNoMergeKey().addAll(MERGE_FIELDS);
        }

        this.getPageCache().put("preUserName", currentUserName);
    }

    super.packageData(packageDataEvent);
}
```

## 关键要点

✅ **三步法实现**：setMergeColums → packageData → exportInitialize

✅ **使用页面缓存**：通过getPageCache保存上一行数据

✅ **NoMergeKey控制**：不同时添加到NoMergeKey取消合并

✅ **导出支持**：exportInitialize设置MergeColumnRule

## 常见问题

**Q：为什么合并没有生效？**
A：检查三个步骤是否都实现了，特别是packageData中的逻辑。

**Q：合并后数据不对？**
A：检查缓存key的唯一性，确保不同字段使用不同的缓存key。

**Q：如何合并多列？**
A：将所有要合并的列添加到MERGE_FIELDS列表中。

**Q：导出Excel没有合并？**
A：确保实现了exportInitialize方法并设置了MergeColumnRule。
